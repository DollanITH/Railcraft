# 连续弯道减速问题修复记录

## 问题描述
在连续弯道下，联挂车辆或单个矿车经过时会出现不合理的减速现象。

## 问题分析
通过代码分析发现，问题出现在`EntityCartBasic.java`的`moveAlongTrack`方法中：

### 问题根源
1. **重复调用applyDrag()**：
   - Minecraft基类的`moveAlongTrack`方法在第650行已经调用了`applyDrag()`
   - EntityCartBasic重写了`moveAlongTrack`方法，但在第216行又调用了`applyDrag()`
   - 这导致了同一帧内应用了两次减速效果

2. **联挂车辆的额外减速**：
   - LinkageHandler中联挂车辆有额外的减速逻辑（LINK_DRAG = 0.95）
   - 在连续弯道时，这个额外的减速与重复的applyDrag叠加，导致明显的减速效果

## 修复方案

### 方案1：移除重复的applyDrag调用（推荐）
在EntityCartBasic.java的moveAlongTrack方法中，移除第216行的`applyDrag()`调用，因为基类已经处理了减速。

### 方案2：修改applyDrag逻辑
如果Railcraft有特殊的减速需求，可以修改applyDrag方法，添加条件判断避免重复减速。
