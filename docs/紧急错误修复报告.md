# 紧急错误修复报告

## 错误信息
```
java.lang.IllegalArgumentException: Block was not a track
at mods.railcraft.common.carts.LinkageHandler.java:201
```

## 错误原因
在`LinkageHandler.java`的`isOnCurve`方法中，直接调用了`TrackTools.getTrackDirection(cart.world, pos, cart)`，但没有检查矿车所在位置是否确实有轨道块。当矿车不在轨道上时（比如在空中或移动过程中），就会抛出此异常。

## 修复方案
修改`isOnCurve`方法，添加轨道存在性检查：

### 修复前（错误代码）
```java
private boolean isOnCurve(EntityMinecart cart) {
    BlockPos pos = new BlockPos(cart);
    BlockRailBase.EnumRailDirection direction = TrackTools.getTrackDirection(cart.world, pos, cart); // 可能抛出异常
    return TrackShapeHelper.isTurn(direction);
}
```

### 修复后（安全代码）
```java
private boolean isOnCurve(EntityMinecart cart) {
    BlockPos pos = new BlockPos(cart);
    // 先检查是否有轨道，避免异常
    if (!TrackTools.isRailBlockAt(cart.world, pos)) {
        return false; // 没有轨道，不算弯道
    }
    BlockRailBase.EnumRailDirection direction = TrackTools.getTrackDirection(cart.world, pos, cart);
    return TrackShapeHelper.isTurn(direction);
}
```

## 修复效果
- ✅ **消除运行时异常**：不再抛出`IllegalArgumentException`
- ✅ **保持功能正确性**：弯道检测逻辑正常工作

- ✅ **向后兼容**：不影响现有功能
