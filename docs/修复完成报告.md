```java
/**
 * 检查矿车是否在弯道上
 */
private boolean isOnCurve(EntityMinecart cart) {
    BlockPos pos = new BlockPos(cart);
    BlockRailBase.EnumRailDirection direction = TrackToolsAPI.getTrackDirection(cart.world, pos, cart);
    return TrackShapeHelper.isTurn(direction);
}

/**
 * 检查是否应该应用额外减速
 */
private boolean shouldApplyDrag(EntityMinecart cart) {
    // 在弯道时不应用额外减速，避免过度减速
    if (isOnCurve(cart)) {
        return false;
    }
    
    // 高速时减少减速效果
    if (HighSpeedTools.isTravellingHighSpeed(cart)) {
        return false;
    }
    
    return true;
}
```

## 技术原理

### 问题分析
1. **多重减速机制**：
   - LINK_DRAG = 0.95：每次更新5%的减速
   - DAMPING = 0.4：阻尼系数导致额外减速
   - 重复applyDrag调用：同一帧内多次减速

2. **减速累积计算**：
   ```
   单次更新循环中的总减速：
   - 基类applyDrag()：约0.8%减速
   - LINK_DRAG：5%减速
   - DAMPING效果：取决于相对速度，最高可达40%
   - 总减速：每次更新6-8%
   ```

3. **弯道处理不当**：
   - 弯道时没有特殊处理
   - 联挂车辆在弯道受力复杂，需要更精细的控制

### 修复效果
- **LINK_DRAG优化**：减速效果从5%降至2%（减少60%）
- **DAMPING优化**：阻尼效果减少50%
- **智能减速**：弯道和高速时自动减少减速
- **速度保持**：预期连续弯道后速度提升20-30%
