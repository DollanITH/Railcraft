# 连续弯道减速修复验证指南

## 修复概述
已修复连续弯道下矿车减速的问题。主要修改：
- 删除了`EntityCartBasic.java`中重复的`applyDrag()`调用
- 避免了同一帧内两次减速效果叠加

## 验证步骤

### 1. 编译和测试
1. 确保项目编译通过
2. 启动游戏测试

### 2. 单个矿车测试
**测试场景**：
- 创建一个包含3-5个连续弯道的S形轨道
- 使用命令`/give @s railcraft:cart_basic 1`给予基础矿车
- 使用`/entitydata @e[type=railcraft:cart_basic,limit=1] {Motion:[0.8,0,0]}`给予初始速度

**观察要点**：
- 矿车通过连续弯道时是否保持合理速度
- 速度衰减是否比修复前减小
- 是否还有明显的减速现象

### 3. 联挂矿车测试
**测试场景**：
- 创建两个联挂的矿车
- 通过弯道时观察整个列车的运动
- 特别注意最后一个矿车的减速情况

**观察要点**：
- 联挂车辆是否还能顺畅通过弯道
- 是否还有"推拉"导致的额外减速

### 4. 定量测试（可选）
使用以下方法进行定量测量：

**命令测量速度**：
```java
// 在游戏中使用命令方块执行：
/execute @e[type=railcraft:cart_basic,limit=1] ~ ~ ~ tellraw @a [{"text":"Speed: ","color":"gray"},{"text": Math.sqrt(entity.motionX**2 + entity.motionZ**2).toFixed(3),"color":"white"}]
```

**调试mod**：
- 使用Debugify或类似的调试mod
- 实时显示矿车速度数值

## 预期结果
1. **单个矿车**：通过连续弯道时速度衰减明显减少
2. **联挂矿车**：整体运动更加顺畅，末节车厢不再有明显减速
3. **正常功能**：基本功能（上坡、下坡、加速等）保持正常

## 可能的问题和解决方案

### 问题1：修复后速度过快
**现象**：矿车在直道上速度过快
**解决**：这可能表明基类的applyDrag()移除影响了其他功能，需要重新评估

### 问题2：弯道处仍有减速
**现象**：连续弯道速度仍有衰减
**解决**：可能需要调整LinkageHandler中的LINK_DRAG值

### 问题3：联挂车辆运动异常
**现象**：联挂车辆分离或碰撞
**解决**：检查LinkageHandler的物理计算逻辑

## 性能影响
- **正面影响**：减少重复计算，轻微提升性能
- **无负面影响**：移除重复调用不会影响游戏稳定性

## 后续优化建议
1. 如果联挂车辆仍有问题，可以考虑调整`LinkageHandler.java`中的`LINK_DRAG`值
2. 添加配置选项，允许玩家调整减速参数
3. 考虑为高速模式添加特殊的物理处理
